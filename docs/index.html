How the real app works
1. Photo in
A front-facing photo is run through pose estimation to find key body points.
2. 3D body
The points fit a parametric 3D body model, which gives measurements.
3. Plan
Weak areas and the user's goal pick exercises, sets and a calorie target.
4. Track
New photos update the model over time to show progress.
